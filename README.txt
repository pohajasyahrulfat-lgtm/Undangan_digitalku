UNDANGAN DIGITAL - TEMPLATE HP

Cara edit:
1. Buka index.html dengan editor kode.
2. Cari nama Fadhillah & Rizky, tanggal, jam, lokasi.
3. Ganti nomor WhatsApp pada link wa.me.
4. Ganti link Google Maps.
5. Untuk musik, tambahkan file musik.mp3 ke folder lalu ubah:
   <audio id="music" loop src="musik.mp3"></audio>
6. Foto bisa ditambahkan kemudian dengan folder images dan tag <img>.

Template ini responsif untuk smartphone dan bisa di-scroll seperti website.
